# محاسبه‌گر دارویی بالینی

وب‌اپ تک‌فایل و موبایل‌محور برای محاسبات دارویی بر بالین بیمار، با ورود صوتی فارسی و انگلیسی.
**دکتر فرشاد فتحی** — متخصص طب اورژانس، فلوشیپ انفورماتیک بالینی

## فایل‌ها

| فایل | کار |
|---|---|
| `index.html` | کل اپ (HTML + CSS + JS داخلی، بدون فریم‌ورک و بدون build) |
| `logo.jpg` | لوگو |
| `manifest.webmanifest`, `sw.js`, `icons/` | نصب روی گوشی (PWA) و کار آفلاین |
| `tests/logic.test.js` | تست‌های پذیرش محاسبات، گفتار، فرمان‌ها و کیبورد (Node + jsdom) |
| `tests/ui.spec.js` | تست ظاهر در 360px و 1280px، روشن و تیره (Playwright) |
| `tests/make-icons.js` | ساخت آیکون‌های PWA از روی لوگو |

## ویرایش داروها

در `index.html` بخش «کتابخانه داروها» بالای اسکریپت است. هر دارو یک خط است:

```js
{c:'vaso', fa:'دوپامین', en:'Dopamine', k:'دوپامین|dopamine',
 m:[{t:'inf', a:200, u:'mg', v:50, du:'mcg/kg/min'}], high:false, note:'آمپول 200 mg/5 mL.'}
```

`t` یکی از `inf` (انفوزیون)، `wb` (دوز وزنی) یا `dhv` (حجم تزریق) است؛ اولین حالت پیش‌فرض است.
بعد از هر تغییر، `npm test` را اجرا کنید و در `sw.js` مقدار `VERSION` را یکی بالا ببرید.

## اجرا و تست

```bash
npm install          # فقط برای تست‌ها (jsdom و Playwright)
npm run serve        # http://localhost:8080
npm test             # تست منطق
npm run test:ui      # تست ظاهر؛ اسکرین‌شات‌ها در tests/screenshots/
```

خود اپ به هیچ نصبی نیاز ندارد؛ `index.html` را در مرورگر باز کنید.

## انتشار با لینک عمومی (HTTPS)

میکروفون مرورگر فقط روی HTTPS کار می‌کند. هر سه گزینه رایگان‌اند:

- **GitHub Pages:** محتوای این پوشه را در ریشه یک مخزن (یا پوشه `docs/`) بگذارید؛
  Settings → Pages → Deploy from a branch. لینک: `https://<user>.github.io/<repo>/`
- **Netlify:** در app.netlify.com/drop پوشه `medcalc` را بکشید و رها کنید.
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → پوشه `medcalc`.

پیش از فرستادن لینک در واتس‌اپ، یک بار روی گوشی باز کنید و از منوی مرورگر «Add to Home screen» را بزنید.

## ایمنی

- همه محاسبات قطعی و محلی‌اند؛ هیچ سرویس یا هوش مصنوعی در محاسبه دخالت ندارد.
- هیچ مقداری از بیمار ذخیره یا ارسال نمی‌شود؛ فقط تب آخر و زبان گفتار در `localStorage` می‌ماند.
- عدد مشکوک هرگز خودکار اصلاح نمی‌شود؛ فقط هشدار داده می‌شود.
- این ابزار جایگزین قضاوت بالینی، دستور پزشک و پروتکل بخش نیست.
