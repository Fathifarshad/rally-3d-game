# NEVA — شبیه‌ساز سه‌بعدی چهره (فاز ۱)

پلتفرم مطب زیبایی **NEVA** — زیر نظر دکتر فرشاد فتحی و دکتر نغمه نوری.

فاز اول: یک شبیه‌ساز تعاملی سه‌بعدی که با حرکت دادن اسلایدرها، نتیجه‌ی تقریبی
دو درمان («حجم‌دهی گونه» و «زاویه‌سازی فک») را به‌صورت زنده روی یک مدل انتزاعی
از سر انسان نمایش می‌دهد.

## اجرا

```bash
npm install
npm run dev      # http://localhost:5174
```

سایر دستورها:

```bash
npm run build    # خروجی پروداکشن در dist/
npm run preview  # سرو کردن خروجی build
npm test         # تست هدلس مدل سه‌بعدی
```

## نکات فنی

- **استک:** React 19 + `@react-three/fiber` 9 + `@react-three/drei` 10 + `three` 0.185، با Vite.
- **نورپردازی:** چیدمان سه‌نقطه‌ای (Key / Fill / Rim طلایی) به‌همراه یک محیط
  استودیویی محلی از `Lightformer` — هیچ فایل HDRI خارجی دانلود نمی‌شود، پس
  پروژه کاملاً آفلاین کار می‌کند.
- **اتصال اسلایدر به مدل:** مقدار هر اسلایدر (۰ تا ۱۰۰) نرمال‌سازی و به‌عنوان
  prop به `HeadModel` داده می‌شود. تغییر مقیاس و موقعیت داخل `useFrame` و با
  `MathUtils.damp` میرا می‌شود تا حرکت نرم و مستقل از نرخ فریم باشد.
  به همین دلیل مقادیر متحرک فقط **یک‌بار** به‌عنوان prop روی گروه اعمال می‌شوند؛
  در غیر این صورت R3F در هر رندر مقدار را مستقیم می‌نشاند و انیمیشن پرش می‌کند.
- **بازخورد بصری:** ناحیه‌ی تحت درمان به نسبت شدت اسلایدر، درخشش طلایی
  (`emissive`) می‌گیرد تا کاربر بداند کدام قسمت در حال تغییر است.
- دوربین به‌آرامی می‌چرخد؛ برای غیرفعال کردن، `autoRotate` را از `OrbitControls`
  در `FaceSimulator.jsx` بردارید.

## گام‌های بعدی (پیشنهادی)

- جایگزینی مدل انتزاعی با یک مدل GLTF واقعی و استفاده از Morph Target به‌جای Scale.
- افزودن درمان‌های بیشتر (لب، بینی، تزریق ژل زیر چشم).
- مقایسه‌ی «قبل / بعد» به‌صورت اسلایدر تقسیم‌کننده‌ی تصویر.
- ذخیره‌ی پروفایل بیمار و خروجی گرفتن از نما برای پرونده‌ی درمانی.
